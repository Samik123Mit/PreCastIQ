Module 01

Smart Maturity Engine

Physics-based real-time strength prediction using the Nurse-Saul Maturity Index — replacing the "wait 24 hours" heuristic with exact science. Phase 1 deployable: zero ML dependency.

Nurse-Saul Maturity Index — ACI 306R-16 / ASTM C1074-11 / Saul (1951)
M = Σ (T − T₀) × Δt
M = Maturity Index (°C·hours)  |  T = Concrete temperature at each 30-min sensor reading  |  T₀ = −10°C (OPC datum, Saul 1951)  |  Δt = 0.5 hours
